💾 Resguardo Integral (Backup en Caliente)

Al presionar el botón de respaldo, el sistema generará de forma automatizada un clon idéntico del archivo de la base de datos actual (`soporte_escuela.db`) con la fecha de la captura.

📥 Restaurar Copia de Seguridad (Carga de Resguardo)

🚀 Migración Masiva de Equipos y Componentes

Pegue el listado de hardware separado por comas utilizando el formato exacto de la base de datos escolar. El motor omitirá de forma nativa los registros duplicados.

Formato Requerido (Sin espacios externos):
sala,tipo_dispositivo,codigo_inventario,marca,modelo,serie

Ejemplo Listo para Copiar:

Laboratorio Computación,Proyector Epson Techo,PRY-LAB-02,Epson,PowerLite,SN-776602
